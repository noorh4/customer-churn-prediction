## Project Overview
This project predicts customer churn using machine learning techniques.  
The goal is to identify customers who are likely to leave the company and provide useful business recommendations to reduce churn.

## Dataset
The project uses the Telco Customer Churn dataset, which includes customer information such as tenure, contract type, internet service, payment method, monthly charges, and churn status.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- SHAP

## Project Steps
1. Data loading and exploration
2. Exploratory Data Analysis (EDA)
3. Data preprocessing and encoding
4. Feature engineering
5. Model training and evaluation
6. Model comparison
7. Explainable AI using SHAP
8. Smart churn risk alerts
9. Next Best Action recommendation system

## Models Used
- Logistic Regression
- Balanced Logistic Regression
- Random Forest
- XGBoost

## Key Features
- Handled imbalanced data
- Compared multiple machine learning models
- Used ROC-AUC, Recall, Precision, and F1-score for evaluation
- Applied SHAP for model explainability
- Built customer risk alerts
- Suggested next best actions for high-risk customers

## Main Outcome
The project helps identify customers with high churn risk and provides recommendations such as contract upgrades, discounts, technical support, and personalized offers.
